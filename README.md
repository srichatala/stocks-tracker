# Stocks Tracker
Stocks tracker is real time app to trace your stocks and see its data.

## This repo has two application Client and Server

### Client:
Client application developed in reactjs.
#### Steps to run client app:
- Clone repo and got app stocks-tracker>client
    - `npm install`
    - `npm run dev`
- once you successfully run the application, you can see following section in app
    - Dahboard
    - Top Stock
    - My Stocks
    - Search Stocks
